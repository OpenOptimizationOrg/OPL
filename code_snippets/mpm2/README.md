# MPM2 (Multiple Peaks Model 2)

Evaluates a function generated by the [Multiple Peaks Model 2](https://github.com/jakobbossek/smoof/blob/master/inst/mpm2.py) — a test problem generator that creates multimodal landscapes by combining randomly distributed peaks on [0, 1]^n. The objective function is a minimization problem with values in [0, 1], where 0 is the global optimum.

MPM2 is part of the [smoof](https://github.com/jakobbossek/smoof) R package and is also available as a standalone Python file.

## Quick Start

1. Install [uv](https://docs.astral.sh/uv/) if you don't have it yet:

```bash
pip install uv
```

2. Download `mpm2.py` and place it in the same directory as `call_mpm2.py`:

```bash
curl -O https://raw.githubusercontent.com/jakobbossek/smoof/master/inst/mpm2.py
```

Your directory should look like:

```
├── call_mpm2.py
└── mpm2.py
```

## Usage

```bash
uv run call_mpm2.py
```

## What the Snippet Does

The script creates a problem instance with 4 peaks in 2 dimensions using random topology, evaluates it at the origin, and prints the result. You can adjust the behavior by editing these variables in the script:

- **`numberOptima`** — number of local optima / peaks in the landscape (default: `4`)
- **`numberVariables`** — problem dimensionality (default: `2`)
- **`topology`** — peak arrangement: `"random"` (uniform) or `"funnel"` (clustered around global optimum) (default: `"random"`)
- **`shapeHeightCorrelation`** — correlation between peak shape and height: `-1` (anti-correlated), `0` (none), or `1` (correlated) (default: `0`)
- **`rotatedPeaks`** — whether peaks use random rotation matrices (default: `True`)
- **`peakShape`** — `"ellipse"` (different radii per axis) or `"sphere"` (uniform radii) (default: `"ellipse"`)
- **`seed`** — random seed for reproducibility (default: `42`)
- **`eval_point`** — the point at which the function is evaluated (default: all zeros)

### How MPM2 Works

Each problem instance is a landscape of overlapping peaks on [0, 1]^n. The objective function returns `1 - max(g(x, peak))` over all peaks, where `g` is a unimodal function parameterized by each peak's height, shape, radius, and covariance structure (based on Mahalanobis distance). The global optimum has value 0, corresponding to the peak with height 1.

### Useful Methods

| Method | Description |
|---|---|
| `objectiveFunction(x)` | Evaluate the problem at point `x` |
| `getLocalOptima()` | Return positions of all local optima |
| `getOptimalSolutions()` | Return positions of global optima |
| `getAllPeaks()` | Return all peak positions as a matrix |
| `getAllHeights()` | Return height of each peak |
| `getAllShapes()` | Return shape parameter of each peak |
| `getAllRadii()` | Return radius of each peak |
| `getActivePeak(x)` | Return the dominant peak at point `x` |
